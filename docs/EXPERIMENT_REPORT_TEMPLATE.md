# 无人机任务规划实验报告

> 使用 `artifacts/evaluation/summary.csv` 的真实数据填写本报告。不得以占位符或估计值替代运行结果。

## 1. 目标与边界

- 输入：中文自然语言任务指令。
- 输出：最多 3 架无人机的结构化航迹规划 JSON。
- 执行验证：仅执行 `selected_drone_id` 对应的单机计划。
- 仿真范围：`x/y ∈ [-0.2, 0.2]m`，`z ∈ [0.2, 0.5]m`。

## 2. 数据集

| 项目 | 数量 | 说明 |
| --- | ---: | --- |
| 训练集 | 400 | 合成任务，规则生成结构化计划后进行受控语言改写 |
| 验证集 | 50 | 不参与梯度更新 |
| 测试集 - 有效任务 | 40 | 用于 JSON、约束和单机仿真评测 |
| 测试集 - 预期拒绝 | 10 | 用于越界或含糊输入的安全拒绝评测 |

记录生成随机种子、模板版本、改写模型、人工抽检数量及发现的问题。

## 6. 代表性端到端案例
